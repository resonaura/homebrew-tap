# 🍺 Homebrew Tap for Resonaura

<img src="https://raw.githubusercontent.com/resonaura/resostage/main/icons/app.png" width="64" alt="ResoStage icon">

Official Homebrew tap for [Resonaura](https://github.com/resonaura) desktop applications.

## Installation

```bash
brew tap resonaura/tap
brew install --cask resostage
```

Or in a single command:

```bash
brew install --cask resonaura/tap/resostage
```

## Available Casks

| Cask | Description | Version |
|------|-------------|---------|
| `resostage` | Live performance audio workstation and stage playback engine | 0.1.0 |

## Updating

```bash
brew update
brew upgrade --cask resostage
```

## Uninstalling

```bash
brew uninstall --cask resostage
```
